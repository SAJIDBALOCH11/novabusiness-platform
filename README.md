# NovaBusiness Frontend

NovaBusiness is a React/Vite frontend.

## Run locally

1. Install Node.js 20+.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

This frontend-only version has no API server or database. Contact and booking forms do not send or save submissions, sign-in is unavailable, and services, portfolio, testimonials, blog, and dashboard data are not connected.
