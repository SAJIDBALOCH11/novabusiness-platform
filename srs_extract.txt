7.2 Security Requirements  Password & Token Security:   Password hashing via   bcrypt   (salt rounds ≥ 12), short-lived JWT access tokens + HTTP-only secure refresh tokens, and expiring password reset/OTP tokens.  Access Control & Hardening:   Role-based authorization middleware on every protected route, login attempt monitoring with lockout thresholds, and API rate limiting.  Injection & Payload Protection:   MongoDB NoSQL injection sanitization, XSS protection headers (Helmet), CSRF protection tokens where applicable, strict input sanitization via Zod, and MIME- type/size validation for   fi le uploads.  Production & Auditing:   Mandatory HTTPS in production, isolated environment variables (   .env   ) for all secrets, and comprehensive audit logging for sensitive administrative changes.  08.
